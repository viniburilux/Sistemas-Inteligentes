# Matriz Privado → Público

**O que foi deliberadamente mantido privado na criação do Sistemas-Inteligentes.**

---

## Princípio

Nunca copiamos código proprietário, dados confidenciais, prompts privados, credenciais ou informações sensíveis. A inteligência derivada foi extraída — o segredo operacional foi preservado.

## Matriz por repositório

| Repositório | O que existe | Publicado | Mantido privado | Justificativa |
|---|---|---|---|---|
| `inteligencia-metalurgica` | Corpus de 72 arquivos com patentes minerais, CSVs, JSONs | Metodologia, taxonomia, arquitetura | Conteúdo de patentes (ZIPs com PDFs de terceiros sob licenças desconhecidas), dados brutos não normalizados | Direitos autorais de terceiros |
| `Lux-Lab/sigmine_mineral_retrieval` | Notebooks de retrieval mineral por embeddings | Método, pipeline arquitetônico | Código GEE proprietário, outputs de candidatos por região | Revelam alvos de investigação |
| `Lux-Lab/machine_lab/` | Blueprint, registries, diagnostic, cycles, composições | Arquitetura conceitual | Execuções específicas, estratégias de prompt | Segredo operacional |
| `LuxMemory` | Memória operacional com dados reais | Conceito, schemas, capacidade | Dados de conversas, paths de acesso | Privacidade de dados |
| ASIE cycles | Ciclos de investigação completos (16+ domínios) | Metodologia, estados epistêmicos | Resultados específicos de cada ciclo | Estratégia de investigação |
| `luxverso-archive/TraceFoundry` | Adaptadores, contratos, manifests | Código e contratos (MIT) | Integrações com sistemas privados | — (código já público) |
