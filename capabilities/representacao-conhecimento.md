# Representação de conhecimento

**Grafos de entidades, séries temporais e redes de citações — reutilizáveis independente de domínio.**

---

## O que é

Um conjunto de representações de conhecimento que modelam domínios de formas diferentes, extraindo os mesmos tipos de insight de problemas distintos. As representações R4, R5 e R6 são 100% reutilizáveis sem adaptação.

## As representações

| Representação | O que modela | Reutilizável |
|---|---|---|
| **R0 — Grafo entidades/relações** | Quem, o quê, como se conecta | ✅ Sim (estrutura universal) |
| **R4 — Temporal** | Quando, está crescendo, quem entrou quando | ✅ Sim (independente de domínio) |
| **R5 — Atores** | Quem são os principais atores, como se relacionam | ✅ Sim (independente de domínio) |
| **R6 — Citações** | Quem cita quem, quais papers são centrais | ✅ Sim (independente de domínio) |

## Caso de uso

No Representation Lab, R4, R5 e R6 foram aplicadas a metalurgia com 2.187 entidades e 18.445 relações usando os mesmos schemas que funcionariam para biotecnologia, energia ou dados públicos. A única diferença são os dados de entrada — a representação é a mesma.

## Por que isso importa

Representações reutilizáveis significam que:
- Não precisa construir um modelo novo para cada domínio
- As perguntas que R4 responde (curvas de adoção, janelas de oportunidade) servem para qualquer área
- Um agente pode pular da análise de patentes minerais para biotecnologia sem trocar de ferramenta

## Evidência

Representation Lab completo em inteligencia-metalurgica (repo privado) com implementação verificada de R0-R6. Relatório disponível no LuxOS.
