# Inteligência Biotecnológica

**Investigação pública de biotecnologia agropecuária com proveniência.**

[Repositório](https://github.com/viniburilux/inteligencia-biotecnologica-agropecuaria) · [Site](https://viniburilux.github.io/inteligencia-biotecnologica-agropecuaria/)

---

## Problema

Biotecnologia agropecuária envolve literatura, patentes, processos industriais, atores e rotas tecnológicas — tudo fragmentado. Investigar um tema como "produção on-farm de Trichoderma" exige cruzar dezenas de fontes e manter rastreabilidade.

## O que construímos

Uma camada pública de inteligência com:

- **Trilhas de investigação**: Trichoderma industrial, Petrobras-microalgas, Pivot Bio, produção on-farm
- **Provenance register**: 763 obras, 2.680 atores, 767 instituições, 4.045 relações (metadata-only, com hash)
- **Estados epistemológicos**: cada achado classificado como observado, inferido, hipótese, contradição
- **Copiloto**: interface de demonstração que responde perguntas de biotecnologia
- **Separação público/privado explícita**: o que está no repo público é projeção; o laboratório privado contém os ciclos ASIE completos

## Resultados

- 8 achados documentados com evidência, limitação e proveniência
- Trilhas legíveis por humanos que mapeiam rotas tecnológicas completas
- Pipeline de aquisição via OpenAlex com dados reais
- Integração com Agro State Adapter para persistência de eventos

## Aplicações

- **Agro**: mapeamento de bioinsumos, organismos, processos e competências
- **Indústria**: scouting de tecnologias biotecnológicas (ex: Trichoderma para cellulose)
- **P&D**: identifica gaps de pesquisa e oportunidades não exploradas
