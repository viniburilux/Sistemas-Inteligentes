# Radar-Contratos-BA

**Dashboard de transparência de contratações públicas artísticas na Bahia.**

[Repositório](https://github.com/viniburilux/Radar-Contratos-BA)

---

## Problema

Contratações públicas por inexigibilidade (sem licitação) são legalmente permitidas para serviços artísticos, mas a justificativa e a transparência variam drasticamente. Cidadãos e órgãos de controle não têm ferramentas para analisar esse gasto em escala.

## O que construímos

Um dashboard interativo (React + Recharts) com:
- **R$ 160,4 milhões** em contratos mapeados
- **1.325 contratos** analisados
- **150 municípios** da Bahia (Jan-Abr 2026)
- Visualização por ranking, evolução temporal e distribuição geográfica
- Design glassmorphism para navegação intuitiva

## Resultados

- Interface funcional e navegável
- Código aberto (MIT)
- Conectado ao pipeline gastos-reais-ba (PNCP + IBGE + SICONFI)
- Base para análise de redes de contratação artística (Rede Artistas Bahia 2025)

## Aplicações

- Transparência pública
- Controle social de gastos
- Jornalismo de dados
- Políticas públicas culturais
